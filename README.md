\# 🤖 Отзывы с модерацией и рейтингом (Telegram‑бот)



Бот для мастеров и небольших студий: клиенты оставляют отзывы с фото и оценкой, администратор проверяет их и публикует в канал. Работает 24/7 в облаке Amvera.



\## 🚀 Что умеет бот



\- \*\*Клиентская часть\*\*

&#x20; - Главное меню с кнопками: «Оставить отзыв», «Посмотреть отзывы», «Отменить»

&#x20; - Пошаговый ввод: текст → выбор звёзд (1–5) → фото (можно пропустить)

&#x20; - Кнопка «Назад» на каждом шаге

&#x20; - После отправки — подтверждение и ссылка на канал с отзывами



\- \*\*Администраторская часть\*\*

&#x20; - Мгновенное уведомление о новом отзыве

&#x20; - Инлайн‑кнопки «Одобрить» / «Отклонить»

&#x20; - Одобренный отзыв автоматически публикуется в Telegram‑канал

&#x20; - Отклонённый отзыв никуда не попадает



\- \*\*Публичный канал\*\*

&#x20; - Посты формируются красиво: оценка в виде звёзд, имя пользователя (без ссылки), текст, фото

&#x20; - Доступен по кнопке «Отзывы» из бота



\## 🛠️ Технологии



`Python 3.12` `Aiogram 3.x` `FSM` `Docker` `Amvera` `SQLite` `Git`
